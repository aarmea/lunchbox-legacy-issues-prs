## Description

Add an `uninstall` command to scripts/shepherd that reverses a from-source
install. It mirrors the `install` command's subcommand layout (bins,
firewall, sway-config, desktop-entry, udev, all) and honors --prefix and
DESTDIR the same way.

`uninstall bins` removes the installed binaries; `uninstall all` removes
every host-global file an install places (binaries, firewall helper +
polkit assets, sway config, desktop entry, udev rule), reloading polkit
and udev afterward to match the .deb postrm. Per-user config under
~/.config/shepherd, group memberships, and the shepherd-firewall system
group are deliberately left in place and reported to the user.

Document the new command in docs/INSTALL.md.
