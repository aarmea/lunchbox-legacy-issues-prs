### `albert` — 2026-05-21 04:18 UTC

As implemented, this PR handles IP range-based filtering only. I have manually validated this by applying the firewall rules the `foot` terminal emulator -- ptyxis spawns a process detached from the shepherd-initiated cgroup, bypassing the firewall. If browsers do the same thing, this will need to be addressed.

This change also splits the CI so that it generates a Docker image first that is then used for the rest of the steps, reducing bandwidth and churn.
