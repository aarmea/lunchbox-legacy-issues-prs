## Description

The real cause of the HTTP 500 on apt publish (not compression — xz and gzip
failed identically). curl's --data-binary defaults the request to
`Content-Type: application/x-www-form-urlencoded`, and Forgejo's package upload
handler treats that (like multipart/form-data) as a form upload and runs the
multipart parser over the body — which fails with
`request Content-Type isn't multipart/form-data` and a 500. Sending an explicit
`Content-Type: application/octet-stream` takes Forgejo's raw-body path, which is
what the Debian registry expects.
