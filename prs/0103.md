## Description

dpkg-deb >= 1.23 (Ubuntu 26.04, and the CI base image) defaults both the
control.tar and data.tar members to zstd. Forgejo's Debian package registry
(Gitea-compat 1.22) can't decompress a zstd control.tar and answers the
apt-registry upload with HTTP 500. Pin xz via `dpkg-deb -Zxz`, which every apt
tool and every Forgejo/Gitea Debian parser understands; it does not affect the
release-asset .deb consumers.

Also surface the server's response body in publish-apt.sh on a non-2xx so a
future upload failure (like this 500) is diagnosable straight from the job log
instead of showing only the status code.
