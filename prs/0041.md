## Description

This change makes it so that sidecars (such as the touch/mouse bridge introduced in [#39](./0039.md)) are terminated when the corresponding activity closes on its own (normal exit, crash, etc.).

This fixes a bug where the bridge stayed alive between activities, breaking touch support in those that already support it.
